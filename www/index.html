A Catalog of the Avian Gut DNA Virome

AvianViromeDB catalogs DNA viruses from the guts of poultry and other birds. It contains 61,608 viral operational taxonomic units (vOTUs) of varying completeness, with quality estimates, source metadata, and computational annotations. The catalog includes complete and partial sequences, with 27,800 entries annotated as at least medium quality.

Scientific Insights

Taxonomic Annotations

Provides predicted taxonomic affiliations with unresolved ranks retained explicitly. Sequence comparisons found 38,093 of 61,608 representatives (61.83%) unmatched in CVD, CMKMC, MGV and IMG/VR v5 at ≥95% ANI over ≥85% of the shorter sequence.

Predicted Functional Annotations

Provides sequence-based predictions of metabolic and other gene functions for reuse and experimental follow-up.

Predicted Microbial Hosts

Provides computational microbial-host assignments for catalog-linked sequences. Bird source metadata describes the sampled material; microbial-host predictions identify candidate hosts for follow-up.

Archived release: October 29, 2026 (version 4), Zenodo record 23768304. Cite this fixed release for reproducibility; the concept DOI provides access to the release history. The catalog metadata preview supports filtering by identifier, quality, length and source coverage, with TSV export, and shows the same 61,608 vOTUs as this release. The Zenodo record also provides the source inventory, member-level source tables, the release manifest and Supplementary Tables S1–S15. Sequence searches and analyses can be run locally using these downloads.

After decompressing a TSV download, open it in a spreadsheet application or a tabular analysis tool. Open the SQLite download with a SQLite client; the schema file lists its tables and columns. In the metadata preview, vOTU_id identifies the operational group and contig_repid identifies its representative sequence. Source assignment and bird source groups summarize retained members; class and family retain unresolved assignments as unassigned.

To search query sequences against the catalog, build a nucleotide BLAST database from the sequence download: gunzip -k vOTUs.fasta.gz; makeblastdb -in vOTUs.fasta -dbtype nucl -out AvianViromeDB; blastn -query query.fasta -db AvianViromeDB -outfmt 6 -max_target_seqs 10.

The archived release contains sequences across quality tiers. Use the CheckV quality and completeness fields to select sequences for downstream analysis. Gene and host annotations describe computational predictions linked to catalog members.
